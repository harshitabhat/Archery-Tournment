
### How to run it locally

Your folder should look like this:

```text
Archeville-Super-Archy-Tournament
│
├── input.json
├── package.json
├── README.md
│
├── src
│   ├── index.js
│   ├── Player.js
│   ├── Team.js
│   ├── ScoreCalculator.js
│   ├── Scoreboard.js
│   └── Tournament.js
│
└── test
    ├── ScoreCalculator.test.js
    └── Tournament.test.js

### Command to run
npm start
